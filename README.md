# Tmeusburger Tap

## How do I install these formulae?

`brew install tmeusburger/tap/<formula>`

Or `brew tap tmeusburger/tap` and then `brew install <formula>`.

Or, in a `brew bundle` `Brewfile`:

```ruby
tap "tmeusburger/tap"
brew "<formula>"
```

## Documentation

`brew help`, `man brew` or check [Homebrew's documentation](https://docs.brew.sh).
